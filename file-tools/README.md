# file-tools
A set of tools for automation of various file operations

# SnapshotMakerApp
Making a Snapshot on a User's computer for further upload to the server

# SnapshotCheckerApp
Checking a Folder with Files to fully match the Snapshot by Checksums, for example, after a User uploaded all the files

# SnapshotAssemblerApp
Looking for the files for a Snapshot (generated by SnapshotMakerApp) and gathering files to recreate the initial folder with files

# FolderSorterApp
Move Folders according to the Set of Rules basing on the names of the Folders
